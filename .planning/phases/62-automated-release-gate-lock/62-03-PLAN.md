## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Git checkout → release gate | Repository state and candidate inputs cross into the verdict authority. |
| Release gate → child process | Commands and diagnostics cross an OS-process boundary. |
| Normalized result → persisted evidence | Only allowlisted, scrubbed evidence may reach disk. |

## STRIDE Threat Register — OWASP ASVS L1

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-62-01 | Spoofing | Candidate identity | high | mitigate | Bind HEAD and critical SHA-256 digests, require a clean commit, and recompare on exit in `release_gate.dart`. |
| T-62-02 | Tampering | Prerequisite graph | high | mitigate | Hardcode the repository-owned wrapper behind `ProcessAdapter`; reject caller-supplied replacement commands. |
| T-62-03 | Repudiation | Gate result | high | mitigate | Persist exact UTC stage records, durable redacted command spelling, exits, and candidate fingerprint in schema-valid JSON. |
| T-62-04 | Information Disclosure | Evidence output | high | mitigate | Collect allowlisted fields only, scrub before object creation, scan JSON/Markdown before writing, and bound diagnostics. |
| T-62-05 | Denial of Service | Child process | medium | mitigate | Enforce per-stage timeouts and terminate timed-out children while recording the classification. |
| T-62-06 | Elevation of Privilege | Verdict computation | high | mitigate | Exhaustive typed verdict computation admits PASS only after identity and the mandatory tracer stage are green. |
