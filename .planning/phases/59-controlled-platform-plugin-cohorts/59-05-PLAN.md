## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App lock to OS biometric prompt | Authentication policy crosses from Flutter into platform LocalAuthentication options and outcomes. |
| Native exception to app-PIN fallback | Untrusted platform errors must not bypass or dead-end the app-owned second factor. |
| Device observation to evidence ledger | Face ID behavior is sensitive and must be recorded only as a redacted result. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-59-21 | Elevation of Privilege | LocalAuthentication options | high | mitigate | Interaction tests require biometricOnly, sensitiveTransaction, and persistAcrossBackgrounding true; no OS-passcode path is accepted. |
| T-59-22 | Denial of Service | Lockout/native exceptions | high | mitigate | Every LocalAuthException code, PlatformException, and residual exception reaches app-PIN fallback. |
| T-59-23 | Spoofing | Native Face ID acceptance claim | high | mitigate | Require exact build/context plus real Face ID and app-PIN observation; unavailable evidence remains non-PASS. |
| T-59-24 | Information Disclosure | Biometric evidence | high | mitigate | Record no PIN, biometric data, device identifier, Keychain item, user data, or credential. |
| T-59-25 | Tampering | local_auth declaration/lock | medium | mitigate | Exact selected/candidate contract and Pub mutation tests reject unreviewed drift. |
