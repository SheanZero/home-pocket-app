## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Manifest/YAML/native text → pure validator | Untrusted structured and source-text inputs are parsed into policy decisions and diagnostics. |
| Validation report → CLI exit status | Severity classification determines whether CI blocks; demotion errors could turn unsafe states green. |
| Parallel/interrupted invocations | Multiple CI/test calls may run concurrently or be cancelled and must not share mutable state or write partial policy. |
