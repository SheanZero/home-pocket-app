## Shared Patterns

### Fail closed, aggregate useful diagnostics

**Source:** [scripts/dependency_compatibility.dart](/Users/xinz/Development/home-pocket-app/scripts/dependency_compatibility.dart:20), lines 20-46 and 206-215.  
**Apply to:** manifest schema, direct inventory, holds, prohibitions, lanes, native inputs, CI.

Accumulate explicit messages in `issues`; emit every finding and return non-zero after checking all inputs. Do not silently accept absent/malformed required manifest fields.

### Contract tests stay hermetic

**Source:** [test/architecture/dependency_compatibility_contract_test.dart](/Users/xinz/Development/home-pocket-app/test/architecture/dependency_compatibility_contract_test.dart:7), lines 7-97.  
**Apply to:** all positive and negative compatibility cases.

Read repository inputs once per fixture factory, mutate copies in memory, and assert a relevant diagnostic substring. No network calls, `pub get`, CocoaPods, SDK installation, or temporary file writes in the test.

### Stable and beta lanes have distinct meaning

**Sources:** [audit.yml](/Users/xinz/Development/home-pocket-app/.github/workflows/audit.yml:27) lines 27-43; [flutter-future-compat.yml](/Users/xinz/Development/home-pocket-app/.github/workflows/flutter-future-compat.yml:19) lines 19-37.  
**Apply to:** checker CLI mode and workflow assertions.

Stable CI is the blocking production contract and must use the committed lockfile. Beta is the scheduled early-warning build lane, never evidence that the Stable baseline changed.

### Privacy/security invariant preservation

**Source:** [ios/Podfile](/Users/xinz/Development/home-pocket-app/ios/Podfile:43), lines 43-65; [dependency checker](/Users/xinz/Development/home-pocket-app/scripts/dependency_compatibility.dart:48), lines 48-59.  
**Apply to:** SQLCipher package/Pod/linker manifest rows and negative tests.

Preserve SQLCipher's functional `0.6.x` package/Pod path and the system SQLite linker-strip marker. Any missing marker, EOL placeholder, or plaintext `sqlite3_flutter_libs` is a blocking error.
