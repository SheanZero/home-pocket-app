# 隐私政策

**Happy Pocket 家庭账本**

制定及最后更新日期：2026年8月5日

生效日期：本应用首次公开发布之日

运营方：ナープ株式会社

## 1. 基本方针

ナープ株式会社（以下简称“我们”）以本地优先、重视隐私为原则提供 Happy Pocket 家庭账本（以下简称“本应用”）。本政策说明本应用及官方网站如何处理信息。

## 2. 设备内账务数据

交易、金额、分类、备注、票据照片等明文账务数据原则上保存在用户设备内。设备数据库使用 SQLCipher，敏感字段使用 ChaCha20-Poly1305，照片等文件使用 AES-256-GCM 保护。

加密密钥由用户设备管理。我们和家庭同步中继服务器均不会取得明文账务数据或解密密钥。当前版本的票据照片只保存在记录它的设备上，不包含在家庭同步或加密备份文件中。

## 3. 外部通信

### 3-1. 汇率

多币种功能会向 Frankfurter、jsDelivr 上的 fawazahmed0 currency-api，以及 Cloudflare Pages 上的同一 API 发送包含日期、基准币种和目标币种的请求。不会发送姓名、联系方式、设备ID、交易、金额、备注、照片或其他账务数据。

### 3-2. 语音识别

语音输入优先使用设备端识别。仅当用户在设置中允许云端回退且设备端识别不可用时，音频才可能由 Apple 或 Google 提供的操作系统语音识别服务处理，具体处理条件适用相应提供方的隐私政策。我们的中继服务器不会接收或保存音频及识别结果。

### 3-3. 家庭同步

用户使用家庭同步时，选定共享的数据会先在发送设备上端到端加密，再将加密消息及传输所需的运营元数据发送至中继服务器。个人账本记录不会共享。

### 3-4. 消息推送

首次公开发布版本已停用消息推送，不会请求通知权限，不会向 APNs 或 Firebase Cloud Messaging 注册令牌，也不会向中继服务器发送推送令牌。

## 4. 家庭同步数据处理

家庭同步数据由中继服务器临时存储和转发。中继服务器不持有解密密钥，因此无法解密交易、金额、分类或备注等内容。

加密消息自创建起有效期为7天。收到接收设备的接收确认后，会从在线数据库删除；未收到确认的消息也会在到期后由每小时运行的任务删除。正常情况下会在到期后约1小时内删除，发生故障时可能延迟至下一次成功处理。

不含消息内容的防重复处理记录保留7天，群组控制事件保留90天，非活跃设备记录在最后访问90天后进入删除范围。设备、公钥、显示名称、群组及成员关系状态等运营元数据，会在提供同步、安全保障和防止滥用所需的期限内保留。已从在线数据库删除的信息可能在轮换备份中最多保留14天。

## 5. 运营日志

中继服务器应用日志可能记录 HTTP 方法、请求路径、响应状态、处理时长、设备ID，以及发生错误时的群组ID。我们不会有意记录请求正文、加密消息正文、公钥、签名、音频、推送令牌或账务数据。生产环境的 PostgreSQL 配置不会把绑定参数写入日志。

访问日志、错误日志和数据库慢查询日志保留30天，期满后通过自动轮转永久删除，不保留这些日志的可恢复备份。

## 6. 使用目的

我们仅为以下目的处理信息：

- 提供本应用、家庭同步、汇率和用户支持
- 验证用户、设备及同步群组
- 排查故障、保障安全并防止滥用
- 履行法律义务

本应用不展示广告，不使用第三方广告或行为分析 SDK，也不会将账务数据用于广告、出售或用户画像。

## 7. 受托处理方与外部提供方

家庭同步基础设施部署于 Tencent Cloud 日本（东京）区域。我们以日本作为账户注册账单国家时，合同主体为新加坡 Aceville Pte. Ltd.；该公司及获准的分处理方依据 Tencent Cloud 合同与数据处理条款，作为我们的处理方处理数据。

汇率服务以及用户允许时 Apple 或 Google 的操作系统语音识别服务，只接收第3节所述的有限信息。除法律要求外，我们不会出售用户信息。

## 8. 用户管理与请求

用户可通过应用内删除功能或卸载应用删除设备内数据。退出或解散家庭群组等操作，可能使相关待传输加密消息早于通常期限删除。

如需请求告知使用目的、查阅、更正、停止使用、停止向第三方提供或删除我们持有的个人信息，请联系 `support@napu.co.jp`。我们会核验请求人与相关设备或同步群组的关系，在合理必要的范围内处理，并原则上在30天内答复。由于采用零知识设计，我们无法读取、恢复或提供用户的明文账务数据。

## 9. 安全措施

我们会根据所处理信息采取访问控制、加密、权限管理、日志管理、备份管理及受托方监督等安全措施。发生信息泄露等事件时，我们会依据适用法律开展调查、降低影响、通知及防止再次发生。
