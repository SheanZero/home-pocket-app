# Apple 官方依据（核对日期：2026-08-04）

- [Upcoming Requirements](https://developer.apple.com/news/upcoming-requirements/) — 自 2026-04-28 起，上传必须使用 Xcode 26 或更高版本及对应 OS 26 SDK。
- [Screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/) — 每类 1–10 张；PNG/JPEG；无 Alpha。iPhone 6.9 英寸接受 1320×2868、1290×2796 或 1260×2736；iPad 13 英寸接受 2064×2752 或 2048×2732。
- [Platform version information](https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information/) — Promotional Text 170 字符、Description 4000 字符、Keywords 100 bytes；Support URL 必填且需包含真实联系方式。
- [App information](https://developer.apple.com/help/app-store-connect/reference/app-information/app-information) — Name/Subtitle 最多 30 字符，Bundle ID 必须与构建一致，Age Rating 必填。
- [Manage app privacy](https://developer.apple.com/help/app-store-connect/manage-app-information/manage-app-privacy) — iOS Privacy Policy URL 必填，并需披露 app 与第三方 SDK 的数据处理行为。
- [App privacy details](https://developer.apple.com/app-store/app-privacy-details/) — “Collect”、linked、tracking、optional disclosure 的官方定义。
- [Privacy manifest files](https://developer.apple.com/documentation/bundleresources/privacy-manifest-files) — `PrivacyInfo.xcprivacy`、收集类型与 Required Reason API 结构。
- [Third-party SDK requirements](https://developer.apple.com/support/third-party-SDK-requirements/) — 常见 SDK 的 privacy manifest/signature 要求。
- [Overview of export compliance](https://developer.apple.com/help/app-store-connect/manage-app-information/overview-of-export-compliance) — 使用标准或自带加密时必须完成出口合规判断。
- [Determine and upload app encryption documentation](https://developer.apple.com/help/app-store-connect/manage-app-information/determine-and-upload-app-encryption-documentation) — 需要文件时的问卷、上传与审批流程。
- [Upload builds](https://developer.apple.com/help/app-store-connect/manage-builds/upload-builds/) — 上传方式、build processing 和工具链说明。
- [Choose a build to submit](https://developer.apple.com/help/app-store-connect/manage-builds/choose-a-build-to-submit) — 选择 build 与 Missing Compliance 处理。
- [Submit an app](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/submit-an-app) — Add for Review 与 Submit for Review 是两个步骤。
- [Set an app age rating](https://developer.apple.com/help/app-store-connect/manage-app-information/set-an-app-age-rating/) — 2026 新年龄分级问卷流程。
- [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/) — 隐私、审核访问、准确元数据和外部支付/打赏相关规则。
- [Offering account deletion in your app](https://developer.apple.com/support/offering-account-deletion-in-your-app) — 若最终产品支持账号创建，必须允许用户在 app 内发起账号删除。
