# coverage-gate-required-files.txt
#
# Blocking per-file coverage scope for hand-written, executable trust-boundary
# code. This replaces cleanup-touched-files.txt, a historical Phase 3-6
# PLAN.md union that mixed generated output, YAML import guards, ARB inputs,
# and stale cleanup paths with production Dart files.
#
# Do not add generated (*.g.dart, *.freezed.dart, *.mocks.dart), generated
# localizations (lib/generated/**), ARB files, YAML import guards, or enum/data
# declarations with no executable lines. coverde intentionally omits those from
# lcov_clean.info. A temporary exception for a hand-written executable file
# must be listed in coverage-gate-deferred.txt with a file-specific rationale.
#
# Scope selection: backup/restore encrypt-and-replace operations and family-sync
# transport/write-barrier paths. Every path below is tracked, hand-written Dart
# with executable coverage obligations. coverage_gate.dart fails if one is
# absent from LCOV, preventing a partial test run or filter change from silently
# shrinking this protection.
