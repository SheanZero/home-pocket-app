# Happy Pocket V17 整 App Mockup

V17 于 2026-08-12 基于当前 Flutter 工作树重新审阅并升级。它延续既有「温润日系 / 生活手帐」设计系统，不重做已稳定的页面，只同步当前代码实现与 V16 之间的可见差异，并把此前缺少独立入口的生产页面补进整 App 页面目录。

## 打开方式

在本目录启动静态服务器后打开：

`http://127.0.0.1:4173/v17/?screen=home`

也可直接打开 [index.html](index.html)。Material Symbols 通过 Google Fonts 加载；家庭头像、引导插画与 5 档满足度图形均使用本地资产。

## V17 本次同步

- 首发设置页移除通知分组和通知开关；语言、识别语言、周起始日、安全、备份、法务与危险操作保持一级直达。
- 统一记账的悦己满足度改为紧凑摘要行，点按后进入 5 档底部面板；交易编辑保留同源的 5 档内嵌选择器。图形尺寸与当前 Flutter 实现对齐。
- 5 档满足度与欢迎引导的价值胶囊全部改用仓库现有真实 SVG 资产；引导页恢复当前代码中的 78px 有机胶囊、语义图标和错落布局。
- 深色类目页应用当前 Flutter 的可读性调色映射，避免深色背景上直接使用过暗的品牌色。
- 家庭付款人标识扩展为稳定的 8 槽身份色；列表中的本人及成员颜色在浅色、深色状态下都保持稳定。
- 家庭成员批准后先显示「正在加入 / 接收密钥」过渡状态，不会提前出现在正式成员列表；加入方补齐密钥恢复状态。
- 家庭统计空数据只显示一处空态说明，去除重复提示。
- 购物页「买うもの / 完了」章节标题增加当前代码中的绿色左侧强调线。
- 补齐统计分类详情、头像选择器、法律正文、PIN 设置、家庭审批 / 确认 / 等待等生产页面的独立目录入口。
- 全局版本标签、页面标题、Inspector 描述和文档升级为 V17。

## 页面覆盖

V17 共覆盖 30 个可直接打开的页面：

| 分组 | 页面 |
| --- | --- |
| Foundation | `foundation`, `states` |
| Main shell | `home`, `list`, `analytics`, `analytics-drill`, `shopping`, `shopping-form` |
| Entry | `entry`, `ocr`, `category`, `edit` |
| Family | `family`, `create`, `approval`, `join`, `join-confirm`, `join-waiting`, `group` |
| Setup & safety | `onboarding`, `onboarding-privacy`, `preferences`, `setup-pin`, `lock`, `settings`, `profile`, `avatar-picker`, `backup`, `legal`, `legal-doc` |

通过 `?screen=<页面名>` 可直接定位页面。工具栏支持 375 / 390 / 430px 三档手机宽度；A1 / A2 / A3 预设分别对应个人浅色、家庭浅色与个人深色。

## 关键交互与状态

- 主页：有 / 无悦己记录，C1 / C2 / C3 灵感签方案，个人 / 家庭切换。
- 明细：年月日、账簿、类目、搜索与排序；家庭付款人身份色。
- 统计：支出 / 悦己主 Tab、周期、趋势、类目 / 成员维度、日历、空态和分类下钻。
- 购物：范围、账簿、私有、类目组合筛选；完成与排序；数量 + 单位、自定义单位和表单校验。
- 记账：键盘、语音待机 / 聆听 / 解析 / 结果、悦己满足度底部面板、连续记账。
- 编辑：日常 / 悦己、JPY / 外币、金额键盘、满足度、保存与删除确认。
- 类目：浏览、搜索、展开、选择、重排、未保存确认和深色调色。
- 家庭：创建、邀请、审批、加入确认、等待、密钥恢复、批准后正在加入与管理。
- 初始设置：两页引导、资料、语言 / 币种 / 识别语言、安全开关、Face ID / PIN 与双次 PIN。
- 设置与数据：个人资料、头像选择、应用锁、备份导出 / 恢复、法务正文及全数据删除确认。

## 实现边界

- 这是用于审阅交互与视觉一致性的单文件 HTML mockup，不替代 Flutter 生产代码。
- 当前产品依旧遵循本地优先与零知识边界；mockup 不模拟任何真实网络、同步、相册或文件系统写入。
- 生产版本号仍由 Flutter 发布配置决定；这里的 V17 指整 App mockup 版本。
- 视觉证据、交互检查、宽度检查与最终结果记录在 [design-qa.md](design-qa.md)。

V17 是当前整 App Mockup 的唯一实现基准。
