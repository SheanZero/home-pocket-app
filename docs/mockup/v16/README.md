# Home Pocket V16 Mockup

V16 由 V15 整 App Mockup 升版而来，并于 2026-07-16 与当前 Flutter App 的主页面及统一记账实现重新同步。

## 打开方式

直接在浏览器打开 [index.html](index.html)。Mockup 为单文件交互稿；Material Symbols 图标字体通过 Google Fonts 加载。

## 统计主 Tab 设计原则

1. **只表达必要的数据归属。** 个人模式的页面上下文已经限定为当前用户，因此使用「支出 / ときめき」，避免重复“我的”；A2 同时混合家庭汇总与个人悦己，必须保留「家族の / 私の」来消除歧义。日、中、英支持文案在 375 / 390 / 430px 基准宽度必须完整显示；省略号只作为异常字号或未知语言的最后兜底，不能作为默认效果。
2. **文字优先于装饰图形。** 标题保持 15px 单行，不通过缩字或改成两行换取空间。空间不足时先压缩辅助图形：常规轨道 38px、图标 34px、图文间距 4px；375px 下轨道 34px、图标 32px、间距 3px。Flutter 实现也应按同一优先级处理，必要时继续缩小或隐藏图形，而不是截断标题。
3. **选中状态像纸片，未选中状态属于底板。** 两个 Tab 共用无边框暖色底板；选中项使用轻微上移、柔和阴影、浅色纸面和顶部色签，未选中项保持平贴。不要增加完整描边、硬阴影或高对比胶囊，以免回到工业化控件观感。
4. **颜色表达账簿语义，不单独承担状态。** 支出使用主绿色，悦己使用樱粉；选中状态还必须同时依靠抬升、纸面与顶部色签表达，保证色觉差异不足时仍可识别。
5. **结构与交互一致。** 两个 Tab 等宽且整块可点击，最小高度 94px；标题、摘要值和辅助图形保持同一信息顺序。实现必须保留 `tablist / tab / tabpanel` 语义、明确的选中状态以及左右方向键切换，并支持减少动态效果设置。
6. **跨语言验收先于交付。** 后续 Flutter 实现需分别核验个人短标题（日文「支出 / ときめき」、中文「支出 / 悦己」、英文「Spending / Joy」）与 A2 归属标题（日文「家族の支出 / 私のときめき」、中文「家庭支出 / 我的悦己」、英文「Family Spending / My Joy」），并在 A1、A2、A3 与 375 / 390 / 430px 宽度下检查无截断、无横向溢出和选中状态一致。

## 核验状态

- A1：个人 · 浅色
- A2：家庭 · 浅色
- A3：个人 · 深色
- 主页悦己状态：有悦己记录 / 无悦己记录；C2「手账便签」为选定方案，C1 / C3 保留对照；全部 CTA 进入悦己记账
- 视口快捷宽度：375 / 390 / 430
- 购物项表单状态：手动 / 聆听 / 解析 / 识别回填 / 编辑 / 麦克风不可用
- 统一记账方案：方案 1「单页连续输入」；唯一 `entry` 页面 + 固定 336px 语音底板；端点模式：3 秒停顿自动解析 + 悦己色按钮立即完成；演示状态：手动 / 聆听 / 识别结果 / 下一笔待机 / 麦克风不可用
- 编辑交易状态：JPY 日常 / JPY 悦己（5 档满足度）/ USD 外币联动 / 保存中 / 删除确认；视觉组件与统一记账同源，交互状态独立于新增账目草稿
- 家庭流程状态：入口 / 分享邀请 / 审批成员 / 输入邀请码 / 确认家庭 / 等待批准 / 家庭管理；Inspector 可直接切换每个状态，创建与加入步骤链保持独立
- 首次启动状态：欢迎引导 1/2 / 欢迎引导 2/2 / 安全保护关闭 / 生物识别 / 应用锁待设置 / 双次 PIN 输入 / 应用锁已设置；Inspector 与页面主操作均可走完整流程
- 备份恢复状态：概览 / 密码过短 / 两次密码不一致 / 加密导出 / 系统分享 / 文件选择 / 替换确认 / 恢复中 / 成功 / 错误密码或损坏文件安全拒绝
- 设置一级状态：周起始日（月 / 日）/ 识别语言（日 / 中 / 英）/ 通知开关 / 全数据删除确认；不再保留「其他设置」二级页，也不显示设备端识别与云端回退控制

V16 是当前整 App Mockup 的唯一实现基准；V15 及其重复副本已由该版本取代。
