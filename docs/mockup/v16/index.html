初始设置 · 安全保护合并方案
交互原则
初始设置选择的是优先解锁方式，不改变 PIN 作为应用锁兜底凭证的安全约束。
Face ID 路径
最终确认时若尚未设置 PIN，先完成双次 PIN 输入，再同时启用应用锁与 Face ID。
演示状态
完成条件
姓名必填；关闭保护可直接开始；任何应用锁方式都必须先有有效 PIN，生物识别只是可选快捷解锁。
设置 · 一级信息架构
一级直达
移除“其他设置”二级入口；识别语言紧接显示语言，周起始日同属“一般”，通知与全数据删除直接放在设置主列表。
安全排序
高频偏好在前，数据任务与法务在后；不可撤销的全数据删除独立放在页面最底部，避免与备份混淆。
演示状态
交互覆盖
周起始日与识别语言可选择；通知可直接切换。关闭 Face ID 回到“仅 PIN”，不会删除 PIN。
设置 · 备份与恢复
现有实现
导出将当前账簿交易、全部账簿与分类、设置和汇率缓存压缩后，以 Argon2id + AES-256-GCM 写入 `.hpb`，再打开系统分享。
恢复边界
仅允许选择 `.hpb`；正确密码后整体替换本地账簿数据。数据库写入在同一事务内，失败时保留恢复前的数据。
演示状态
Mockup 补强
当前 App 在选文件、输密码后直接恢复；本稿增加“现有数据将被替换”的显式确认，并把错误反馈落在任务上下文中。
